# ONCE14 · Referencia pública de agronegocios

Caso Katort completamente ficticio. Nombres, cifras, series y conclusiones son simulados. No contiene información privada ni un RFC real. Publicación autorizada únicamente como referencia educativa.

Ruta: `/referencias/agronegocios/` y `/referencias/agronegocios/katort/`.

Los modelos se mantienen separados: presupuesto financiero base, simulador de sensibilidad, econometría sobre series sintéticas y evaluación de inversión ilustrativa. No confundir escenarios con evidencia de mercado o asesoría para un cliente real. El alcance de la póliza debe contratarse individualmente.

Archivos de la ficha: index.html, styles.css, model.js, app.js, economics.js, economics-ui.js, service.js, service-ui.js. Recursos de marca compartidos con el sitio principal. Sin librerías remotas, formularios, login ni carga de documentos.

Para nuevos clientes, usar datos verificados, documentar fuentes y supuestos, validar estados y deuda, y alojar el expediente fuera de este espacio público con autenticación real. RFC y URL no constituyen control de acceso.

Reversión: eliminar exclusivamente los archivos de `referencias/agronegocios/` agregados por esta publicación, mediante un nuevo commit. La portada y DNS no se modifican.
